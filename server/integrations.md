# ENVYBOX.SERVICE

1) getEnvyToken()  
Получает токен для доступа к API EnvyCRM


2) getEnvyBoxCalls(gte, lte)
Получает список звонков за указанный период  
Возвращает упрощённые данные о звонках (телефон, статус, цена, ID)



# LEADORUB.SERVICE

1) getLeadsFromLidorubCRM(gte, lte)  
Получает лиды за указанный период
Фильтрует только целевые (statusOKK === true)
Для каждого брокера считает сумму минусов (по 20 за каждого лида)
Возвращает список брокеров с их количеством лидов и общими минусами



# RESIDENCE.SERVICE

1) getResidenceToken()  
Получает токен для API Residence через логин и пароль


2) getBrokersListWithRole()
Получает список брокеров с их ролями, исключая админов, уволенных и стажеров


3) getBrokers(token)
Получает список брокеров (имя и ID сотрудника), фильтруя по наличию employeeId


4) getBrokerByEmployId(lead, users)
Находит брокера по employeeId из списка пользователей


5) getLeads(token, gte, lte)
Получает лиды за период (начало и конец)


6) getCallsByDate(token, gte, lte)
Получает звонки за период, фильтруя по статусам и собирая данные



# UIS.SERVICE

1) getUIScalls(token, gte, lte, users)  
Получает звонки из API UIS за указанный период (по дате создания)
Для каждого звонка ищет соответствующего пользователя по employeeId
Определяет брокера по найденному пользователю
Собирает и возвращает массив звонков с информацией о телефоне, employeeId, брокере и всей информации о звонке



# ZVONOBOT.SERVICE (MAIN)

1) getZvonobotMailings(token, gte, lte)
Получает список активных рассылок из Zvonobot за указанный период
Использует модель finishedMailingsModel для получения завершённых рассылок
Получает данные о рассылках с API Zvonobot по страницам
Фильтрует рассылки по имени (определённые ключевые слова) и статус
Возвращает массив активных рассылок с информацией о дате, имени, id, статусе и других параметрах


2) prepaingMailing(mailing, token)
Обрабатывает отдельную рассылку
Получает звонки, связанные с этой рассылкой, по страницам
Для каждого звонка с ivrDigit === 5 создаёт объект лида с данными
Подсчитывает общее количество звонков, лидов и расходы
Возвращает обновлённый объект рассылки с добавленными лидами и статистикой
